# Enterprise Retail Data Audit

An end-to-end retail analytics project using **Python and Power BI** to identify sales performance, inventory risk, overstock, no-sales SKUs, and actionable business insights.

## Business Problem

Retail businesses can lose working capital through excess inventory, slow-moving products, and poor visibility of sales performance. This project creates an enterprise-style audit to identify these risks and support better retail decision-making.

## Key Insights

- Total Revenue: **$73.21M**
- Gross Profit: **$21.10M**
- Gross Margin: **28.82%**
- Total Quantity Sold: **1.68M units**
- Inventory Value: **$38.91M**
- Overstock SKUs: **4,843**
- Severe Overstock SKUs: **4,775**
- No-Sales SKUs (30 Days): **3,887**
